# 🍯 Miel Doña Carolina - Landing Page

Sitio web y landing page oficial para la promoción y venta de productos de **Miel Doña Carolina** (miel 100% natural, pura y artesanal).

## 🌿 Características
- Presentación de la marca Doña Carolina.
- Catálogo interactivo de productos.
- Formulario de contacto y pedidos directos vía WhatsApp.
- Diseño totalmente adaptable a dispositivos móviles (Responsive Web Design).

## 🛠️ Stack Tecnológico
- **Frontend**: HTML5 Semántico, CSS3 Moderno, JavaScript Vanilla.
- **Control de Versiones**: Git & GitHub.
- **Despliegue**: Vercel.

## 📂 Estructura
```text
Landing Miel/
├── assets/          # Imágenes de productos, logo e íconos
│   └── images/
├── styles/          # Hojas de estilo CSS
│   └── main.css
├── scripts/         # Lógica interactiva en JavaScript
│   └── main.js
├── index.html       # Estructura principal
├── .gitignore       # Archivos y carpetas excluidos del control de versiones
└── README.md        # Documentación del proyecto
```
